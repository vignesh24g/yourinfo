# 🔍 YourInfo – What Your Browser Knows

Ever wondered **how much your browser already knows about you**?  
**YourInfo** is a stylish, interactive dashboard that reveals the information websites can access through standard browser APIs.  

👉 **Live Demo:** [Visit YourInfo on GitHub Pages](https://vignesh24g.github.io/yourinfo)

---

## ✨ Features
- 📱 **System Details** – Browser, OS, language, timezone, screen resolution  
- 💻 **Hardware Info** – CPU cores, RAM, GPU renderer, pixel ratio  
- 🌐 **Network Insights** – Connection type, downlink speed, RTT  
- 🔋 **Battery Status** – Level and charging state  
- 📍 **Location** – Geolocation (with user consent)  
- 🌎 **Public IP** – IP address, ISP, region, country  
- 🎤 **Media Devices** – Cameras, microphones, speakers available  
- 🎮 **Sensors** – Orientation and motion data (if supported)  
- 🍪 **Other Data** – Cookies, localStorage, sessionStorage availability  

---

## 🎨 Why This Project?
Most users don’t realize how much information is exposed by their browser.  
This project is built to **raise awareness** and show, in a clean UI, what websites can learn about you without installing anything extra.
